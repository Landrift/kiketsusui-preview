# 気血水体質診断 — 結果画面プレビュー

デザイン確認用のプレビューです。実装時と同じフォント・配色で、5タイプの結果画面を確認できます。

**公開URL:** https://landrift.github.io/kiketsusui-preview/

- `index.html` — トップページ（5タイプへのリンク）
- `result.html` — 結果画面（`?type=kikyo` 等で切り替え）

結果画面上部の黒いバーはプレビュー用で、実装には含まれません。

## 反映済みの方針

- 診断結果は全項目を公開（ロック・段階開示なし）
- 漢方名・虚実スコアは非表示（医師管理画面のみで参照）
- CTA は「医師に相談する」
